Text styles


HTML (Hyper Text Markup Language) is the most basic building block of web


It defines the meaning and structure of web content Other technologies besides html are generally used to describe web pages appearance presentation (CSS) or functionality behavior(Javascript)



The HTML style attribute is used to add style to an element, such as colors, font, size, and more.



Bold The"b" tag in HTML is used to specify the bold text without any extra importance. The test is written within "b" tag display in bold size. You can do that by using font-weight : bold ; property in CSS. It is a container tag that contains and open tag, content & closing tag



Italic- The "i" tag defines a part of text in an alternate voice or mood. The content inside is typically displayed in italic. The "i" tag is often used to indicate a technical term, a phrase from another language, a thought, a strip, name, etc.



Underline- The "u" tag in HTML stands for underline and it's used to underline the text enclosed within in this "u" tag. This tag is generally used to underline mispelled to words. This tag requires a starting as well as ending tag.
